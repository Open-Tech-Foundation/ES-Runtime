# Ops that dispatch with no capability check (D247).
#
# Guest code can call every op there is — an Isolate's too, which holds no
# capability and is stopped only by each op's own check. So every op here must
# be one of:
#   - a pure function of its arguments (codecs, parsers, crypto, URL work);
#   - an act on a handle the calling agent owns, minted by a gated op and
#     checked for ownership (D50) — net_read, http_respond, pg_query, …;
#   - a provider no flag gates by design (clock, entropy, console, stdio).
# The test `every_ungated_op_is_one_that_was_reviewed` fails when an op is
# added without a capability and is not here. Adding one is a review: say why
# it qualifies, beside it, if the reason is not one of the three above.
