# {{name}}

A bare ES-Runtime project — a server that answers with a greeting, and
nothing else. Edit `src/index`, and it reloads on save under `npm run dev`.

- `npm run dev` — rebuild, run, and keep both current (`esdev start`)
- `npm run build` — the production bundle into `dist/`
- `npm start` — run the bundle the way production does (`esrun dist/index.js`)
- `npm test` — the test files (`esdev test`)
