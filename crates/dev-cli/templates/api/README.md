A JSON API on [ES Runtime](https://esrun.opentechf.org). Start with
`src/server.ts`; the greeting lives in `src/hello.ts`.

```sh
{{pm}} install
{{pm}} run dev     # http://localhost:8080
{{pm}} run test
{{pm}} run build   # dist/server.js
{{pm}} run start   # runs the build with only the permissions it needs
```
