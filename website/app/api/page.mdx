# API reference

ES-Runtime is ESM-only and deny-by-default: a run reaches what the command line
that started it named, and nothing else. Host functionality is exposed as ES
modules under the `runtime:` scheme — never as ambient globals — and every
operation is gated on an explicit capability.

## The `runtime:` scheme

Built-in modules are imported with a `runtime:` specifier. They are served from a
baked, in-binary registry before any injected loader runs, and never touch the
filesystem. The security boundary is the **op**, not the module: importing always
succeeds, but an operation throws unless its capability has been granted.

```js
import { env, args } from "runtime:process";
```

## Built-in modules

| Module | Status | Permission |
| --- | --- | --- |
| [`runtime:context`](/api/context) | Available | **—** |
| [`runtime:diagnostics`](/api/diagnostics) | Available | `diagnostics` / `diagnostics-detail` |
| [`runtime:process`](/api/process) | Available | `env` / `signals` (`args`, `exit` and `permissions` need none) |
| [`runtime:path`](/api/path) | Available | `env` (only to read `cwd()`) |
| [`runtime:fs`](/api/fs) | Available | `read` / `write` |
| [`runtime:net`](/api/net) | Available | `net` / `listen` |
| [`runtime:http`](/api/http) | Available | `listen` |
| [`runtime:websocket`](/api/websocket#server) | Available | `listen` |
| [`runtime:db`](/api/db) | Available | `read` / `write` for a `sqlite:` file; `net` for a network database |
| [`runtime:serialization`](/api/serialization) | Available | — |
| [`runtime:hashing`](/api/hashing) | Available | — |
| [`runtime:images`](/api/images) | Available | — (`read` / `write` for a `file()`) |
| [`runtime:pdf`](/api/pdf) | Available | — (`read` / `write` for a `file()`) |
| [`runtime:archive`](/api/archive) | Available | — (`read` / `write` for a `file()`) |
| [`runtime:system`](/api/system) | Available | `run` |
| [`runtime:workers`](/api/workers) | Available | `workers` (and `imports` for a file entry); durable workers `read` / `write` |
| [`runtime:wasi`](/api/wasi) | Available | — to construct; its file calls need `read` / `write` |
| [`runtime:build`](/api/build) | Available — **`esdev` only** | `read` (`write` to `write()`) |
| [`runtime:test`](/api/test) | Available — **`esdev` only** | — |
| [`runtime:watch`](/api/watch) | Available — **`esdev` only** | `read` |
