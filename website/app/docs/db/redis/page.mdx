# Redis

The Redis driver gives `runtime:db` a Redis-shaped connection while keeping the
portable database API honest about the features Redis can support.

## Redis guide

- [Concepts and connections](/docs/db/redis/core) — URLs, RESP3, types, and the
  first connection.
- [Transactions and blocking commands](/docs/db/redis/transactions) —
  pipelining, MULTI/EXEC, pub/sub, and blocking operations.
- [Operations and reliability](/docs/db/redis/operations) — cluster, Sentinel,
  pooling, reconnecting, timeouts, and errors.
- [Compatibility and limits](/docs/db/redis/compatibility) — performance,
  portability, and unsupported features.

For the portable API and driver contract, see
[Databases](/docs/db) and [Writing a database driver or an ORM](/docs/db/authoring).
