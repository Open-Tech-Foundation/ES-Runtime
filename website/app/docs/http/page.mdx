# HTTP server

Build a server with Web-standard requests and responses, then choose the focused
guide for routing, lifecycle, protocol features, or deployment behavior.

## HTTP guide

- [Basic servers and requests](/docs/http/basics) — start a server, route requests,
  stream bodies, and handle disconnects and errors.
- [Lifecycle and graceful shutdown](/docs/http/lifecycle) — shutdown hooks,
  signals, and draining.
- [HTTPS, HTTP/2, and trailers](/docs/http/protocols) — secure transport and
  protocol-specific features.
- [Identity, limits, and deployment](/docs/http/production) — caller identity,
  timeouts, connection limits, and Hono.

For design rationale, see the [HTTP server internals](/docs/internals/http).
