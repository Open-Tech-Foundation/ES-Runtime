# esdev test

Find and run test files with the assertion vocabulary provided by
[`runtime:test`](/api/test). Both `.test.` and `.spec.` files are discovered
in the supported JavaScript and TypeScript extensions.

```sh
esdev test                    # every *.test.* and *.spec.*
esdev test math               # ...whose path contains "math"
esdev test --file=x.test.ts   # exactly one file
```

## DOM tests

Pass `--dom` when a test needs the browser-like DOM surface currently provided
by esdev. It installs a fresh realm for each isolated test file, including
`document`, the core node and event classes, and strict `innerHTML` parsing.
It is test-runner-only: ordinary `esdev` runs do not receive these globals.
The current selector surface includes `querySelector`, `querySelectorAll`,
`matches`, `closest`, attribute selectors, selector lists, and structural
combinators, plus logical, structural, `:nth-*()`, and `:focus`
pseudo-classes, form/link state, and `:scope`; unsupported selector syntax
throws `SyntaxError`.
`HTMLElement`, `HTMLInputElement`, `HTMLButtonElement`, `HTMLFormElement`, and
`HTMLLabelElement`, `HTMLSelectElement`, `HTMLOptionElement`, and
`HTMLTextAreaElement` are also available, with common reflected attributes,
select values/options, form reset, and the basic checkbox, radio, and
submit-button click defaults. Controls associate with a containing form or its
`form` attribute; `new FormData(form)` serializes successful controls.
Disabled `fieldset` and `optgroup` ancestors disable their descendant controls
for validation and form-data serialization.
Labels resolve their `for` target or nested control; checkbox and radio groups
use their form owner when applying click defaults.
Input and textarea values, plus checked controls, retain their markup defaults
and are restored by `form.reset()`.
Number and date inputs normalize their values and expose `valueAsNumber` and
`valueAsDate` without locale or layout dependencies.
Inputs, selects, and textareas expose layout-free constraint validation
(`validity`, `checkValidity()`, `reportValidity()`, and custom errors); form
`requestSubmit()` validates before dispatching `submit`.
Inline styles are supported through `element.style` and stay synchronized with
the `style` attribute. `getComputedStyle` exposes those inline values only;
stylesheet cascade and resolved values are not present.
`customElements` supports registration, lookup, `whenDefined`, and upgrades;
its registered elements receive connected, disconnected, adopted, and observed
attribute callbacks.
Focus is tracked without layout: supported controls and elements with a
`tabindex` can use `focus()` and `blur()`, update `document.activeElement`, and
dispatch the standard focus event sequence.
`MutationObserver` records child-list, attribute, and character-data changes
and delivers them at the microtask checkpoint; subtree, attribute-filter, and
old-value options are supported.
`document.createRange()` supports node and text boundary points, text extraction,
boundary comparisons, contextual fragments, cloning, extraction, insertion,
deletion, surrounding contents, and automatic boundary adjustment.
The DOM realm also includes in-memory `location`, `history`, `localStorage`,
and `sessionStorage`. Animation frames use the test clock, while media, resize,
and intersection observers are safe never-firing stubs.

```sh
esdev test --dom
```
