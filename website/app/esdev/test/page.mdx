# esdev test

Find and run test files with the assertion vocabulary provided by
[`runtime:test`](/api/test). Both `.test.` and `.spec.` files are discovered
in the supported JavaScript and TypeScript extensions.

```sh
esdev test                    # every *.test.* and *.spec.*
esdev test math               # ...whose path contains "math"
esdev test --file=x.test.ts   # exactly one file
```

## Test guide

- [Writing tests](/esdev/test/writing) — assertions, helpers, and table-driven
  cases.
- [Running and isolating tests](/esdev/test/running) — filters, process
  boundaries, and hangs.
- [Mocks, setup, and imports](/esdev/test/mocks) — mock behavior, clocks,
  budgets, reports, and module resolution.

Exits non-zero if any file fails.
